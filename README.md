# HAI Task Bot dashboard

The stable, bookmarkable copy of the HAI Task Bot status dashboard, served by
GitHub Pages.

The bot itself runs on a PC and exposes its API through a Cloudflare quick
tunnel whose hostname changes on every restart. This page reads
`endpoint.json` (which the bot rewrites whenever its tunnel comes up) to find
the current address, and talks to the bot's API from your browser with an
access token you enter once. The token is kept in your browser only; it never
touches this repository.

- `index.html` is generated by `npm run build-pages` in the bot repo. Do not edit it here.
- `endpoint.json` is written by the bot. Do not edit it here either.
